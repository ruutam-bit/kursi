## Detalizētās prasības

### Tehnoloģijas

| Prasība | Īstenojums |
|---|---|
| Flask | Flask 3.1, viens process; servera pusē renderēts HTML; nav JavaScript |
| Jinja2 | `templates/` — `base.html` (izkārtojums), `macros.html` (formu lauki), ekrānu šabloni |
| SQLite | `data.db` (ceļš maināms ar `CRM_DB`); shēma un sākumdati `db.py`; ārējās atslēgas ieslēgtas |
| Codespace + Claude Code | Izstrādāts GitHub Codespace vidē ar Claude Code, ievērojot `CLAUDE.md` |
| MI | `anthropic` SDK (pēc izvēles); bez tā — imitācija |

### Faili

### Sākumdati (sintētiski)

- N4.1 Datubāze un sākumdati tiek izveidoti automātiski pirmajā pieprasījumā, ja lietotāju tabula ir tukša.

| Dati | Skaits | Piezīme |
|---|---|---|
| Lietotāji | 5 | 3 darbinieki, 1 vadītājs, 1 administrators |
| Organizācijas | **10** | 5 uzņēmumi, 3 NVO, 2 pašvaldības; sadalītas starp darbiniekiem |
| Kontaktpersonas | **20** | 2 katrai organizācijai; 2 ar beigušos glabāšanas termiņu |
| Mijiedarbības | **30** | Pēdējās ~90 dienās, katrai ar vienu dalībnieku |
| Pieprasījumi | 8 | Visos statusos, 3 kavēti |
| Uzdevumi | 6 | Daļa šodien, daļa nokavēti, daļa nākotnē |

- N4.2 Datumi sākumdatos tiek rēķināti no šodienas, lai «kavēts» un «šodien» vienmēr būtu redzami.

### Iestatījumi

| Mainīgais | Nozīme |
|---|---|
| `CRM_DB` | Datubāzes ceļš |
| `CRM_SECRET_KEY` | Sesijas atslēga (ja nav — ģenerē katrā palaišanā) |
| `CRM_AI_OFFLINE=1` | Vienmēr lietot MI imitāciju |
| `ANTHROPIC_API_KEY` | Claude piekļuve (pēc izvēles) |
| `AXE_PATH` | Lokāls `axe.min.js` pārbaudei bez tīkla |

### Palaišana

```bash
cd sandbox/crm
pip install -r requirements.txt
flask --app app run --debug
```
