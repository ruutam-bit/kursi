## Mērķis

Glabāt organizāciju kontaktpersonas — fiziskas personas — tikai tādā apjomā, kāds vajadzīgs saziņai (VDAR datu minimizācija).

## Maršruti

| Metode | Maršruts | Darbība |
|---|---|---|
| GET, POST | `/organizacijas/<id>/kontakti/jauns` | Jauna kontaktpersona |
| GET, POST | `/kontakti/<id>/labot` | Kontaktpersonas labošana |

## Detalizētās prasības

### Dati (pilns lauku saraksts — citu lauku nav)

| Lauks | Obligāts | Noteikums |
|---|---|---|
| Vārds, uzvārds (`name`) | jā | Nedrīkst būt tukšs |
| Amats (`position`) | nē | Brīvs teksts |
| Darba e-pasts (`email`) | viens no diviem | Formāts `x@y.z` (`^[^@\s]+@[^@\s]+\.[^@\s]+$`) |
| Darba tālrunis (`phone`) | viens no diviem | 8–15 cipari un atstarpes, var sākties ar `+` |
| Saziņas tiesiskais pamats (`basis`) | jā | `ligums` (Līgums ar organizāciju), `legitimas_intereses` (Leģitīmās intereses), `piekrisana` (Piekrišana) |
| Pamata datums (`basis_date`) | jā | Derīgs datums `GGGG-MM-DD`, ne nākotnē |
| Glabāt līdz (`retain_until`) | aprēķināts | Pamata datums + 3 gadi (29. februāris → 28. februāris) |

- F2.1 Sistēmā **nav** lauku personas kodam, adresei, dzimšanas datumam vai brīvām piezīmēm par personu.
- F2.2 Formas augšā ir paziņojums: ievadīt tikai darba kontaktdatus, neievadīt personas kodu, adresi vai privātas piezīmes; dati glabājas 3 gadus no pamata datuma; izmaiņas tiek žurnalētas.
- F2.3 Jaunai kontaktpersonai pamata datums pēc noklusējuma ir šodiena.
- F2.4 Labojot pamata datumu, glabāšanas termiņš tiek pārrēķināts.
- F2.5 Pēc saglabāšanas — pāradresācija uz organizācijas kartīti pie sadaļas `#kontakti` un paziņojums «Kontaktpersona pievienota.» / «Kontaktpersonas dati saglabāti.».

### Validācija un kļūdu ziņas (422, kļūdu kopsavilkums + teksts pie lauka)

| Gadījums | Kļūdas teksts |
|---|---|
| Tukšs vārds | Ievadi vārdu un uzvārdu. |
| Nederīgs e-pasts | E-pasta adresei jābūt formā vards@iestade.lv. |
| Nederīgs tālrunis | Tālrunim jābūt 8–15 cipariem, piemēram, +371 20001234. |
| Nav ne e-pasta, ne tālruņa | Norādi vismaz e-pastu vai tālruni, lai būtu iespējams sazināties. |
| Nav pamata | Izvēlies saziņas tiesisko pamatu. |
| Nederīgs datums | Ievadi pamata datumu formātā GGGG-MM-DD. |
| Datums nākotnē | Pamata datums nevar būt nākotnē. |

### Attēlošana kartītē

- F2.6 Organizācijas kartītē kontaktpersonas ir tabulā: Vārds, Amats, E-pasts (`mailto:` saite), Tālrunis, Saziņas pamats ar datumu, Glabāt līdz, Darbība «Labot».
- F2.7 Ja glabāšanas termiņš ir pagājis, blakus datumam ir atzīme «Termiņš beidzies» ar ikonu un tekstu.
- F2.8 Zem virsraksta ir teksts: kontaktpersonas ir fiziskas personas; kartītes atvēršana tiek reģistrēta; dzēšanu veic administrators.

### Piekļuves žurnāls

| Notikums | Ieraksts (`kontakts`) |
|---|---|
| Izveide | izveidots |
| Labošanas formas atvēršana | atvērta labošanai |
| Saglabāšana | mainīts: `<mainīto lauku nosaukumi>` (vērtības netiek žurnalētas) vai «mainīts: bez izmaiņām» |

### Tiesības

- F2.9 Kontaktu var pievienot un labot tikai organizācijai, kas lietotājam ir redzama ([N3](N3.md)); citādi **404**.
- F2.10 Darbinieks un vadītājs kontaktu **dzēst nevar**; dzēšana — [N2](N2.md).
